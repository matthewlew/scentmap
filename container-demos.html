Consolidated Container Rules

1. Universal Left-Alignment
Containers must never center-align content by default. Use align-items: flex-start and text-align: left for all cards, banners, and carousel items.
2. Standardized Padding
Static cards use var(--sp-lg) (16px). Interactive/Carousel cards use var(--sp-md) (12px) to optimize for density.
3. Typography Mapping
Use .text-ui-strong or .list-item-label for primary names. Supporting text always uses .text-meta. Descriptions use .text-body.
4. Proximity Logic
Related elements (Dot + Name) use var(--sp-xs) (4px) gap. Distant blocks (Title + Description) use var(--sp-md) (12px) gap.
