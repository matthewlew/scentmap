## 2024-03-14 - Mobile Filter Toggle ARIA State Management
**Learning:** Even simple toggle buttons that show/hide panels using standard CSS classes (like `open`) need explicit ARIA state synchronization (`aria-expanded` and `aria-controls`) to communicate their function and state to screen readers.
**Action:** When implementing show/hide toggles via JavaScript `classList.toggle`, always capture the returned boolean state and immediately sync it to the triggering button's `aria-expanded` attribute. **Learning:** In dynamically generated JavaScript templates (like the Trial Bench list), icon-only buttons (like '✕' for delete) are frequently rendered without `aria-label`s, causing screen readers to incorrectly read the symbol character out loud instead of the intended action.
**Action:** Always inspect JS template literals for `<button>` elements containing only symbols or icons, and explicitly inject descriptive `aria-label` attributes (e.g., `aria-label="Delete test bench entry"`) during the rendering cycle.
