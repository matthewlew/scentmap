Hierarchy Consistency Rules

1. Header Grouping
The Breadcrumb, Title, Chip, and Description must live in a single u-gap-md header container. Description follows the title immediately.
2. Card Consistency
All internal match/action cards (like quiz-match-card) must match carousel cards in background (bg-primary) and border (border-standard).
3. List-Style Alignment
Carousel cards must use a horizontal row layout (dot + u-flex-column) to align with standard list-item aesthetics.
4. Archetype Hierarchy
Use Scent Archetypes as the breadcrumb for quiz-related intelligence.
